# 글꼴과 라이선스

Lamplight에 함께 들어 있는 글꼴입니다. 각 글꼴은 아래 라이선스를 따르며, 앱과 함께 재배포할 때 이 폴더의 라이선스 파일을 같이 둡니다.

| 파일 | 글꼴 | 저작권 | 라이선스 |
| --- | --- | --- | --- |
| `lineseed-kr-bold.woff2` | LINE Seed KR Bold | © LY Corporation | SIL Open Font License 1.1 — [`LINESEED-OFL.txt`](LINESEED-OFL.txt) |
| `MaruBuri-Bold.otf` | 마루 부리 Bold | © NAVER Corp. · NAVER Cultural Foundation | SIL Open Font License 1.1 (Reserved Font Name: MaruBuri) — [`MARUBURI-OFL.txt`](MARUBURI-OFL.txt) |
| `galmuri11*.woff2`, `galmurimono11.woff2` | 갈무리 11 · 갈무리 모노 11 | © 2019–2025 Lee Minseo | SIL Open Font License 1.1 — [`GALMURI-OFL.txt`](GALMURI-OFL.txt) |

- 마루 부리는 배포처에서 받은 원본 파일 그대로입니다. OFL의 예약 글꼴 이름(MaruBuri)이 있어 변환하지 않았습니다.
- 모두 SIL Open Font License 1.1 글꼴만 넣습니다. 앱에 넣어 배포하는 조건이 분명하지 않은 글꼴(예: KoPubWorld — 프로그램 임베딩에
  별도 승인이 필요하다고 안내)은 넣지 않습니다.
- LINE Seed KR은 OFL(예약 글꼴 이름 없음)이라 woff2로 변환해 넣었습니다.
- 글꼴 자체를 유료로 판매하는 것은 모든 라이선스에서 금지됩니다.
